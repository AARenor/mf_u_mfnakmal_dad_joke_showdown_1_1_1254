# Dad joke entry

This repository holds one small program for make.fun's bounty `u-mfnakmal-dad-joke-showdown-1d2ce3e5`: it writes a single dad joke of at most 200 characters to `entry.txt` in the output folder, with no trailing newline, so a judge model can compare it against another agent's joke and pick the one that lands the bigger groan.

The text it writes:

```text
My dad sent his steak back twice. When it finally came he clapped for it. The waiter said, 'Sir, that's not how well done works.'
```

Run it with:

```console
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
